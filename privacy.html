隐私政策

你的笔记在哪里，会发给谁

生效日期：2026 年 11 月 26 日 · 适用于 MochiMind 桌面软件 v2.1 及以后版本（本次更新对应 v4.0.2）、网页试用版，以及本网站

存在本机

画板只在你的设备上

卡片、笔记、附件和设置都保存在本机（网页版保存在你的浏览器里）。没有账号，开发者看不到你的画板。

提问才发出

只发给你选的模型

提问时，问题和带上的附件会发送给你选择的模型服务来生成回答。

不收集

不追踪、不出售

没有统计分析、没有广告、没有崩溃上报，也不会把数据卖给或分享给任何人。

1这份政策说的是什么

MochiMind 是一款由个人开发者维护的 Windows 桌面软件（下文的"我们"指开发者）。这份政策说明软件会处理哪些信息、存在哪里、什么时候会发送给第三方，以及你可以怎样删除它们。

MochiMind 不要求注册账号，不在任何服务器上保存你的内容。桌面软件没有自己的服务器；唯一经过我们服务器的，是网页试用版用「自带」模型提问：为了不把模型服务的密钥放进网页，这类提问会先经过我们的转发服务器 api.mochimind.cc，再由它转给模型服务（详见第 3 节）。转发服务器只负责转发，不保存问题、回答和图片。

2保存在你电脑上的内容

以下内容都保存在本机的 %APPDATA%\MochiMind 文件夹里，不会上传到我们这里：

  • 画板：每张卡片的问题、AI 的回答、思考过程、笔记、排版和样式；
  • 附件：你拖入或粘贴的文件、图片，文件夹整理出的摘要，以及 AI 生成的图片；
  • 设置：主题、上次使用的画板和模型、是否已看过首次提问提示等；
  • 你手动添加的 API：服务地址和密钥。密钥只在本机的后台服务里使用，软件界面拿不到完整密钥；
  • 阅读模式打开的书（PDF）和你选作壁纸的图片：和附件一样保存在本机；
  • 你上传的文档模板（.css）、阅读进度与色调、壁纸和背景音乐的偏好、界面语言：保存在软件自己的本地存储里。

背景音乐里「本地音乐」选择的音乐文件，只在这次打开软件期间直接从你的电脑播放，不会被复制、保存或上传。自带的钢琴曲和环境音都在软件内部，播放时不联网。

网页试用版（在线试用）不安装到电脑上：以上内容（包括你在网页版里填的 API 密钥）保存在你这个浏览器的本地存储里，同样不会上传给我们。换浏览器或清除浏览器里本网站的数据，这些内容就会消失。

3什么时候会有内容离开你的电脑

只有在下面几种情况下，软件才会把内容发送出去，而且只发给完成这件事所需的那一个服务：

你在做什么发送的内容发给谁
提问、追问你的问题；勾选"带上前文"时前面几张卡片的问答；引用的段落；附件（图片原图、文本文件的内容）你当前选择的模型服务
网页试用版用「自带」模型提问同上（问题、前文、引用、图片附件）先到我们的转发服务器 api.mochimind.cc，再转给自带模型的第三方服务。转发服务器不保存内容；为了限制每人每天的免费次数，会在内存里按 IP 地址计数，每天零点（北京时间）清空，不写入磁盘
阅读模式里「问 AI」「问这一页」你选中的那段文字，或当前这一页的文字（连同书名和页码），作为问题的一部分你当前选择的模型服务。整本书不会被发送，只发送你提问时带上的文字
生成图片图片描述（会自动带上上一张卡片的主题）图片生成服务；生成的图片会下载回本机保存
拍照提问你拍下并选择「用这张」的照片（拍照过程中的画面不会保存或发送）照片作为附件保存在本机；提问时随问题发送给你选择的模型服务
语音输入你说话的录音语音识别服务；转成文字后录音即丢弃，不会保存
获取模型列表对应服务的 API 密钥（用于身份验证）该密钥所属的服务
背景音乐里的「音乐软件」不发送任何内容，只是在浏览器里打开网易云音乐 / QQ 音乐的公开歌单或榜单页面对应的音乐网站（适用它们自己的隐私政策）
导出 PDF / HTML / 图片不发送任何内容：文档在本机生成，保存到你选择的位置—
检查更新只读取一份公开的版本信息；请求里只带软件名和版本号，不含任何个人信息或笔记内容本网站（GitHub Pages）。可在「关于与支持」里关闭"启动时自动检查更新"

"你选择的模型服务"取决于提问框下方的模型来源：

  • 自带：由第三方模型服务提供商提供（模型列表见首页）；
  • 手动：你自己填写的服务地址，提问框会显示它的域名（网页版由你的浏览器直接发给该服务，不经过我们）；
  • 本机：如果是 Ollama、LM Studio 这类在本机运行的模型，内容不会离开你的电脑；如果是 Claude Code、Codex 等命令行工具或 CC Switch，内容会交给这些工具，再由它们按各自的设置发给对应的服务。

这些服务如何处理收到的内容，适用它们各自的隐私政策和服务条款。软件在你第一次提问前会在提问框里提示一次内容的去向。

建议不要在问题或附件里放身份证号、银行卡号、密码等敏感信息。

4软件会读取的本机信息

为了自动找到你电脑上已有的模型来源，软件会在本机读取以下信息：

  • CC Switch 的配置；
  • Claude Code、Codex 命令行的位置（包括 Claude、Codex 桌面版自带的命令行），以及它们是否已登录：只检查有没有登录记录（例如登录文件是否存在、配置里是否写了账号或密钥项），不读取、不保存、不发送其中的凭据；
  • 环境变量里的 API 密钥（例如 OPENAI_API_KEY）；
  • 本机 Ollama、LM Studio 等本地模型服务的地址。

这些信息只在本机使用。为了列出可用的模型，软件会用找到的密钥向该密钥所属的服务查询模型列表，不会发给其他任何地方。

在设置里点「一键登录」时，软件会在你的电脑上打开 Claude Code 或 Codex 自己的登录窗口，登录过程由它们和对应的官方服务完成，MochiMind 接触不到你的账号和密码。

5我们不做的事

  • 不要求注册账号，不收集姓名、手机号、邮箱（你主动发邮件联系时，我们只用你的邮箱回复你）；
  • 没有统计分析、用户行为追踪或崩溃上报；
  • 没有广告；
  • 不会出售、出租或分享你的任何数据。

6安全措施

  • 软件的后台服务只在本机地址 127.0.0.1 上运行，每次启动生成一次性的随机令牌，其他程序无法调用；
  • 软件窗口在沙箱中运行，只开放剪贴板、字体、麦克风和摄像头权限；麦克风只在你点击麦克风按钮时使用，摄像头只在你打开「拍照」面板时开启，关闭面板就会停止；
  • API 密钥只在后台服务里使用，界面和错误提示中都不会出现完整密钥；
  • 网页版「自带」模型的密钥只存放在转发服务器上，网页里没有；转发服务器只接受本网站发来的请求，全程 HTTPS 加密，不记录访问日志。

7查看、导出和删除你的数据

  • 在软件里删除卡片或画板，对应内容就会从本机删除；不再被任何卡片使用的附件会自动清理；
  • 可以把画板导出为 PNG、PDF、Markdown 或 .mochimind 文件，自行备份或换电脑；
  • 在模型设置里可以随时删除你添加的 API 和密钥；
  • 想清除全部数据：卸载软件后，删除 %APPDATA%\MochiMind 文件夹即可；网页版在浏览器设置里清除本网站的数据即可。

已经发送给第三方模型服务的内容，需要按照该服务的规定向它申请删除。

8未成年人

MochiMind 适合用于学习。未满 14 周岁的用户，请在父母或其他监护人的同意和指导下使用，提问时同样不要填写个人敏感信息。

9关于 AI 生成的内容

回答、思考过程和图片由 AI 模型生成，可能出错或不准确，尤其是公式推导和数值计算。请把它当作学习参考，重要结论请自行核对。

10本网站

本网站由 GitHub Pages 托管，网页不使用 Cookie，不加载统计脚本或任何第三方资源。网页试用版用浏览器的本地存储（IndexedDB 和 Service Worker）保存你的画板，这些数据只在你的浏览器里。GitHub 作为托管方可能会记录访问日志（例如 IP 地址），这部分由 GitHub 隐私声明约束。

11政策更新

软件的数据处理方式发生变化时，我们会更新这份政策并修改顶部的生效日期；如果是重要变化，会在网站或软件中明显的位置说明。
